# SFTP 独立窗口

点击远程会话标签栏的 **SFTP** 打开文件窗口。左侧为本地目录，右侧为该 SSH 会话的远程目录。再次点击 SFTP 会聚焦已有窗口；切换终端标签不会改变文件窗口关联的服务器。关闭文件窗口不关闭 SSH 会话，关闭 SSH 标签会关闭对应文件窗口。

## 文件操作

- 单击文件或目录只选择；双击目录才进入。双击文件不会自动传输。
- Shift 点击连续选择，Ctrl 点击增减选择；Mac 同时支持 Command 点击。
- 在已选项目上右键，保留整个选区；在未选项目上右键，改为选择该项目。
- 左侧右键“上传所选”传到右侧当前目录；右侧右键“下载所选”传到左侧当前目录。可以混选文件和目录。
- 目录递归传输，包含子目录、空目录和隐藏文件；也可把本地文件或目录拖进 SFTP 窗口上传。
- 两侧均可用上级按钮返回父目录，或输入路径按回车跳转。

## 同名目标

目标存在时，传输暂停并显示目标路径，选择覆盖或跳过。已有目录需确认合并；内部同名文件仍逐个确认。跳过目录会跳过其整个子树。文件与目录类型不一致时终止该项并报错，不自动删除原目标。当前不复制符号链接或设备文件。传输为复制/合并，不会删除目标侧独有文件。

传输期间目录导航和新增右键传输暂停，避免目标目录改变；显示当前文件进度。关闭确认窗口视为跳过，不默认为同意覆盖。

## 验证

```sh
cargo test --workspace --offline
cargo build --offline --bin ssh-client
./target/debug/ssh-client
```

macOS 自动测试通过系统 `/usr/libexec/sftp-server` 的标准输入输出运行真实 SFTP 协议，无需服务器账号。覆盖目录往返、中文路径、空目录、多块文件、双向覆盖/跳过、覆盖前等待及文件/目录冲突。界面另有 Shift/Ctrl/Command 选择和关闭确认测试。

手工验收：打开两个 SSH 会话的 SFTP 窗口，分别设置本地和远程路径；检查单击/双击、混合多选右键上传下载、同名目标覆盖及跳过；切换终端标签后确认文件窗口仍操作原服务器。
